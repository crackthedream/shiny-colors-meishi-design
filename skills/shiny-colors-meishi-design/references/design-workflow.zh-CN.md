# 设计方法：固定流程，按角色与卡面构图

适用于《偶像大师 闪耀色彩》的制作人/担当交换名片。英文对应文件：[design-workflow.en.md](design-workflow.en.md)。此方法适合新做、改单张和整理整套；继续已有项目时，从尚未完成的阶段开始。

## 1. 明确这一次做什么

从用户当前要求和已确认记录中提取：角色、用途、已选素材、张数、正反面内容、允许的构图变化、需要保留的版本、交付格式。用途会影响信息量：长期交换名片、生日纪念与活动限定款不能共用未经讨论的默认文案。

只补问会改变设计的决定。用户说先调研再选图时，先交候选册；已经指定卡面时，不重复组织选图。批量制作前先完成一款样张，是验证方法的默认工作方式；用户已授权整套推进时沿用授权。无需把每次常规排版调整变成审批步骤。

尺寸由用户或印厂要求决定。无规格时可提出 85.60 × 53.98 mm、圆角 3.18 mm、文字安全边距 3 mm 作为本例起点，明确它是可改的设计参数。出血、纸材、颜色配置和双面方向应在进入印刷交付时按实际要求处理。

**本阶段完成：** 已有可执行的范围，以及仍需用户决定的少数问题；不把未答的选择当成已批准。

## 2. 做能支持选择的调研

Agent 主动查找公开可访问的角色官方介绍、游戏官网/活动页、官方宣传与卡面资料，并可获取可用图片；不把找素材默认转交给用户。以具体来源核对角色名、卡名、卡面版本与作品归属。搜索缩略图只用于定位，正式分析应实际打开较清晰的图像。

如果只有社区图库能提供所需版本，可在来源记录中准确标成社区镜像，并另列官方交叉核名证据。官方出处页面与实际下载图像可能来自不同站点，分开记录。无法访问或暂未核对的内容写明状态，不把推测写成事实。保留素材自带的署名和版权标记。

为每个候选建立轻量记录：

| 字段 | 用途 |
| --- | --- |
| 稳定编号、角色、原文卡名、版本 | 确保用户说“02B”时不会错图；A/B 的含义在候选册中说明 |
| 页面 URL、图像 URL、来源类别、核验日期 | 区分官方获取、镜像获取与未核实出处 |
| 尺寸和实际观看状态 | 说明画质是否足够以及分析是否基于实图 |
| 主色与情绪、人物和环境关系 | 说明为什么适合该角色与本次用途 |
| 裁切风险、可用信息区 | 保住脸、手势、重要道具和叙事关系 |
| 背面可提取线索 | 从服装、光线、花形、建筑节奏等推导图形 |

候选册把图和建议并置，让用户直接看差别。推荐组合应比较情绪、构图和颜色的互补关系；张数和主题从选择中形成，不预先把所有角色塞进四季或统一和风模板。

**本阶段完成：** 候选图已看过、编号对应准确、来源分类明确，用户可据此选择。选定后记录精确版本。

## 3. 从所选画面建立设计语言

先写一段短设计意图：这张最有辨识度的线索是什么，正反面分别如何使用它，姓名与联系信息怎样参与。对同一角色也重新看每张图；舞台、日常、清冷、俏皮等面貌可能并存。

| 源图线索 | 可转成的平面手段 | 判断是否成立 |
| --- | --- | --- |
| 风、发丝、斜向光线 | 曲线、色带、斜切信息区 | 方向呼应画面，主信息仍可读 |
| 服装滚边、刺绣、织物层次 | 细框、局部花饰、间隔与层叠 | 图形有节制，不用一个放大的裙摆轮廓承担整面 |
| 建筑透视或窗框 | 递进边框、错位框线、节奏间距 | 空间感来自比例变化，而非等距机械重复 |
| 水面、雨线、花朵、光斑 | 疏密线群、抽象花瓣、少量点色 | 能追溯到这张图，而非通用装饰贴纸 |

这些是推导例子，不是选项菜单。套装的一致性主要来自信息层级、字体角色、边距和制作质量；每张的主图形、颜色比例、留白和标题走向可以不同。借鉴另一角色成品时只提取方法，重新证明本卡为何适合这种构图。

## 4. 把正面作为完整设计

在成品比例内试裁切，再安排文字。按选定的设计方向安排人物与环境的视觉重心，可以突出人物，也可以让两者共同构图。脸在画内不代表构图完整，倒影、伸手方向或灯光关系也可能是关键。

信息区可以借用真实留白，也可以通过有形状的色面、边栏、细框或局部遮罩重新组织。形状的方向与比例要与图中动势呼应。复杂暗背景未必适合小字，浅色光斑也不等于稳定留白；实际渲染后看对比。

角色名、卡名、制作人身份与装饰题字分别定层级。名片需要清楚的身份时，给制作人姓名与担当区足够分量；长标题可拆成有节奏的行组。把所有内容排成同一条底栏只是一个可能选项，不应成为跨卡通用解法。

构图可裁切、缩放或叠加独立信息层；保留原图副本和来源标记。若用户要求保持插画本身不变，图像内容与新增排版分层处理并在导出时核对。

## 5. 背面与字体一起设计

默认使用可编辑文字、线条、色面与矢量图案。把源图线索抽象成有主次的构图，让文字和图形共同形成视觉重心。官方签名或组合标识只在需要且可用时少量使用，并标明来源。

先决定姓名、担当、标题与联系信息的阅读顺序，再选字。正文/信息字与展示字各有职责；中日文必须有对应字形。细字和浅色字要在接近实物大小的预览中检查，避免大屏看似精致、印小后不可读。斜体、书写体和特殊字重也应从实际文件核验，不能只依赖系统回退。

字体文件、子集、转曲与嵌入都应按对应字体许可处理。可编辑 SVG 留活字；需固定外观的交付另存转曲稿，不覆盖源文件。

只有用户明确要求 AI 图像时才加入该分支。记录生成图与官方素材各自的身份，并将生成版本与平面主用版本清楚区分；生成图不会自动成为所有后续卡的默认路线。

## 6. 样张评审与迭代

选择一款能够验证本轮难点的正反面样张：可能是最复杂的画面、最难放文字的一款，或最能代表用户审美的一款。每轮展示同尺寸正反面对照，附一两句“从什么线索出发、这次改了什么”。

把反馈转成可观察的修改：

- “机械”先检查比例、对齐、重复间距与文字是否只是贴上去；调整层级和构图，不靠增加装饰补救。
- “潦草”先看图形的完整性、曲线收口、疏密和细节尺度；保留必要线索，减少随意几何堆叠。
- “不贴角色”回到这张实图的服装、神态、环境和色彩，重新推导，而非套用前一角色。
- “柔和但要醒目”从主次、明暗、形状节奏和留白建立张力，不只降低饱和度。

记录本轮保留与修改的面。样张通过后扩展其余卡，但逐张处理裁切和文字位置。已认可的面不因改另一面而无故变化。

**本阶段完成：** 用户已确认样张方向或已授权相应批量工作；整套能逐面说明其与源图的联系。

## 7. 填入个人信息并整理交付

允许姓名、担当、联系方式、社交与短句等字段按需求存在，联系方式的数量和平台不固定。用户未提供或要求省略的字段，删除其标签、占位符和多余分隔线，再调整剩余内容的位置。不要用星号、省略号或虚构号码填满空位。教学示例可使用明确的示例身份和保留域名。

真实信息写入后检查最长字符串、缺字和对比；同步重出 SVG、转曲稿、PNG、总览与交付清单。HTML 中修改信息并保存，并不自动更新之前导出的图片，须明确这一点。

如需公开参考版，从干净的示例数据重新导出。除可见文字，还要检查 SVG 的 `aria-label`/`title`/`desc`、HTML 模板、脚本常量、JSON 报告、图片像素和元数据。真实联系方式、制作人昵称、私人路径与聊天记录不应进入公开包。只扫描文本不能证明栅格图已经脱敏。

## 8. 导出和检查的边界

至少保存可编辑源与供用户审阅的正反面预览；转曲 SVG、PNG、PDF、拼版等按约定需要输出。用实际毫米尺寸与目标分辨率计算像素尺寸；提高导出 DPI 不会恢复原图细节。

逐面核对：姓名和联系信息一致、无空标签/占位符、字形完整、文字无溢出、人物关键部位无意外裁切、文字背景对比足够、正反面配对正确。套装总览用于比较整体，放大单面用于检查细节；两者都要看。

附带的 [SVG 文字工具](svg-tools.md) 可检查或转曲其支持的水平单段文字，按明确字体映射报告字形覆盖与实际字形边界。它对 `tspan`、复杂文字整形、文字及祖先变换、CSS 样式表或额外行内样式等不支持的布局应报错；遇到这些情况，改用能准确整形的编辑器/渲染器，或在不改变设计意图的前提下简化结构，再渲染复核。不要将部分检查成功写成整稿通过。

3 mm 等安全距离只能是本次设置；视觉平衡、装饰细节、背景对比和印厂要求不由工具自动证明。浏览器交互未实际测试时如实标明；RGB 成品尺寸校样也不自动等于带出血、色彩转换和双面拼版的印刷文件。

**最终完成：** 交付目录指向本轮最新文件，用户能看全正反面，个人字段已核对，来源和第三方材料边界清楚，已测与未测项明确。原始批准版保留，历史迭代不混进“最新”目录。
